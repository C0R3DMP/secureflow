✅ React Frontend: To use the modern React dashboard, build the frontend first.

📦Setup Instructions

The React frontend needs to be built before the dashboard is available. Run these commands:

cd frontend && npm install && npm run build

Or use the setup script:

bash setup-frontend.sh

🚀Quick Start

Once the frontend is built:

python -m secureflow server-launch

Then open your browser to:

http://localhost:5000/ui

📚Documentation

For more information, see:

  • 📖 Frontend Documentation

🔧Development Mode

For development with live reload:

cd frontend && npm run dev

This starts Vite dev server on http://localhost:3000 with proxy to backend.
